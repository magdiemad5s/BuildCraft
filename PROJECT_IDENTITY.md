# Project identity

The release-facing project name is **BuildCraft Neo**.

This name is intentionally separate from compatibility identities:

- `buildcraft` remains the shared legacy resource/data namespace.
- `buildcraftlib`, `buildcraftcore`, `buildcraftbuilders`, `buildcraftenergy`,
  `buildcraftfactory`, `buildcraftsilicon`, `buildcrafttransport`, and
  `buildcraftrobotics` remain public mod and registry namespaces.
- `buildcraftcompat` remains an optional companion namespace.
- The current development artifact prefix `buildcraft-neo-*` is an artifact
  coordinate, not a registry migration.

No branding change may rename a legacy ID, NBT key, SavedData name, packet
meaning, recipe/tag path, or world-facing block-entity identity.
